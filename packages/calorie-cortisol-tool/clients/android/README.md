# Android Client — Calorie & Cortisol Tool

Kotlin / Jetpack Compose · TensorFlow Lite (on-device inference) · Health Connect.

Scaffolding only. Camera capture, TFLite inference, the Health Connect bridge, and
the biometric prompt are implemented in later tasks. Shared local-first logic lives
in `@calorie-cortisol/client-shared`.

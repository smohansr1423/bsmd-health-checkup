# iOS Client — Calorie & Cortisol Tool

Swift / SwiftUI · Core ML (INT8 on-device inference) · HealthKit · AVFoundation.

Scaffolding only. Camera capture, on-device inference, the HealthKit bridge, and
the biometric gate are implemented in later tasks. Shared local-first logic lives
in `@calorie-cortisol/client-shared`.

## Toolchain

- Build/test: Swift Package Manager (`swift build`, `swift test`).
